System Architecture

How data flows from the climber's wrist to the basecamp dashboard entirely off-grid.

Wristband → Mobile App → Climber Node → Repeater → Basecamp

The system relies on a 433MHz LoRa mesh network for 15km+ range, completely bypassing expensive satellite networks ($400+ hardware, $15-65/month subscriptions) and resolving the critical issue of zero cellular coverage in deep valleys.

Smart GPS Filtering

Rejects GPS jitter, teleport jumps, and low-satellite anomalies. Mobile phone GPS acts as an automatic fallback.

Accelerated SOS

Dedicated hardware panic button immediately triggers 1-second interval telemetry with maximum transmission priority.

Vitals Monitoring

Continuous heart rate monitoring via a custom ESP32-H2 BLE wearable, relayed straight to the rescue dashboard.

Two-Way Messaging

Send and receive critical text messages between basecamp and the mobile app via the LoRa hardware bridge.

Mesh Networking

Autonomous repeater nodes extend signal over mountain ridges using smart TTL-limited multi-hop routing.

Commercial Portal

Full e-commerce platform (Next.js) for device purchasing, device registration, and secure OTA firmware distribution.
