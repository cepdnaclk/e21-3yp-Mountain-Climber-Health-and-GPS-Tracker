MountainSafety Basecamp Dashboard - Windows

How to use:

1. Extract this ZIP file.
2. Connect the MountainSafety Basecamp device to the laptop using USB.
3. Double-click MountainSafetyDashboard.exe.
4. Wait a few seconds.
5. Your browser should open automatically.
6. If it does not open, manually open:

   http://127.0.0.1:5000

Important:
- Keep the Basecamp device connected by USB while using the dashboard.
- Do not close the black command window while using the dashboard.
- Close Arduino Serial Monitor before using this dashboard.
- If the dashboard does not detect the device, unplug and reconnect the USB cable, then restart the app.
- Normal customers do not need to know the COM port. The app auto-detects the Basecamp ESP32.
- Advanced/admin override: set Windows environment variable MCS_SERIAL_PORT, for example MCS_SERIAL_PORT=COM30.

You do not need:
- Python
- Arduino IDE
- VS Code
- Terminal commands
- Source code
